VTRA · RACE DIRECTOR SUITE · MOCKUPS FOR DECISION

One race record, from the first idea to the finisher's certificate

Four zones. Race is the nine modules below, around a single race record. Community, Coach and More features sit beside it. You set the race once (name, date, categories, capacity, budget) and every module reads from it. Click a module card to open its screen; every screen is a clickable mockup with sample data.
