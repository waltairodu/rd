Races

Races come from your findmybib collections.

Every collection whose ID starts with Import is a race, named after the collection's display name in the Wix CMS (Import910 is VHM). To add a race, upload its list to a new collection such as ImportUltribe with the display name Ultribe, then press Refresh.

Sample data

Load 20 example runners to try the desk, then remove them before the expo opens. Example runners are never mixed into your real list.

Sync runners from findmybib

Copies the runners in the selected race's findmybib collection into the expo list. Safe to repeat any time; it adds new runners and updates details, and never changes what has been handed over.

Import runners

          
Paste rows from Excel or load a CSV. Columns: bib, name, category, T-shirt size, phone. A header row is detected. Only new runners are added. Registered runners are never changed, their T-shirt size included. Only the findmybib sync updates registration details, and your findmybib collection itself is never written to.

Staff logins

          
Logins are kept in the Wix CMS, in the ExpoStaff collection. Add one row per person: username, password, role (admin or desk). The three desks are fixed in the software: Desk 1 - BIB, Desk 2 - Tshirt, Desk 3 - Misc. Leave desk empty to let that login choose any desk, or enter 1, 2 or 3 (several separated by commas) to limit it. Delete the row to remove access.
